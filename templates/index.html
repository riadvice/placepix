SVG Placeholder Mode

Zero-processing wireframe placeholders. Perfect for layouts and mockups.

/svg/400/300?bg=e2e8f0&fg=64748b
/svg/400/300?bg=1a1a2e&fg=e94560&text=Hero
/svg/400/300?bg=10b981&fg=fff&text=CTA

Parameters:

bg — background hex color
fg — text hex color
text — custom label (default: width×height)

Color Manipulation

Apply filters and color adjustments to any image on the fly.

Sepia Tone

?sepia=1

Blue Tint

?tint=3b82f6

Brighten & Contrast

?brightness=1.3&contrast=1.2

High Saturation

?saturation=2.0

Grayscale

?grayscale=1

Dramatic Red

?tint=e11d48&brightness=0.8&contrast=1.3

Parameters:

?tint=3b82f6 — hex color overlay
?brightness=1.3 — 0.0 to 2.0
?contrast=1.2 — 0.0 to 2.0
?saturation=2.0 — 0.0 to 2.0
?sepia=1 — warm sepia tone
?grayscale=1 — black & white

Search by Dominant Color

Find images that match your brand palette. Every image is scanned for its top 3 dominant colors.

Blue

/color/3b82f6/400/300

Green

/color/10b981/400/300

Red

/color/e11d48/400/300

How it works:

/color/{hex}/{w}/{h} — dedicated color route
?color=3b82f6 — filter any endpoint by color
/api/color/{hex} — list all matching images
/api/info/id/1 — includes colors: [...]

API Reference

All endpoints support CORS and return images with long-term cache headers.

GET /{width}/{height}/{category}

Random image from a category

GET /{width}/{height}

Random image from all categories

Query Parameters

?grayscale=1Grayscale
?blur=2Gaussian blur (1-10)
?seed=abcDeterministic image
?text=HelloText overlay
?fit=cropResize mode
.avifAVIF output (smaller)
.webpWebP output
.pngPNG output (lossless)
